# 📖 Emniyet-Kritik Sistemler Terminoloji ve Kısaltmalar Sözlüğü (Glossary)

| Kısaltma | Açılımı | Standardı | Tanım |
| :--- | :--- | :--- | :--- |
| **ARP** | Aerospace Recommended Practice | SAE | Havacılık tavsiye edilen mühendislik uygulamaları |
| **ASIL** | Automotive Safety Integrity Level | ISO 26262 | Otomotiv emniyet bütünlük seviyesi (ASIL A - D) |
| **CCF** | Common Cause Failure | ARP 4761A | Ortak kök nedene bağlı çoklu bileşen arızası |
| **COTS** | Commercial Off-The-Shelf | Genel | Ticari hazır raf ürünü donanım veya yazılım |
| **DAL** | Design Assurance Level | DO-178C / DO-254 | Tasarım güvence seviyesi (DAL A - E) |
| **EARS** | Easy Approach to Requirements Syntax | Rolls-Royce / INCOSE | Kural tabanlı açık gereksinim yazım sözdizimi |
| **FADEC** | Full Authority Digital Engine Control | Havacılık | Tam yetkili dijital uçak motor kontrol sistemi |
| **FCC** | Flight Control Computer | Havacılık | Fly-By-Wire uçuş kontrol bilgisayarı |
| **FHA** | Functional Hazard Assessment | ARP 4761A | Fonksiyonel tehlike değerlendirmesi |
| **FMEA** | Failure Mode and Effects Analysis | MIL-STD-1629 | Hata modu ve etkileri analizi (indüktif) |
| **FTA** | Fault Tree Analysis | IEC 61025 | Hata ağacı analizi (dedüktif, Boolean cebri) |
| **GSN** | Goal Structuring Notation | Emniyet Dosyası | Emniyet argümanlarını görsel modelleme dili |
| **HIL** | Hardware-in-the-Loop | Test / Doğrulama | Gerçek donanımın sanal simülatörle testi |
| **HLR** | High-Level Requirements | DO-178C | Üst seviye yazılım gereksinimleri |
| **IMA** | Integrated Modular Avionics | ARINC 653 | Entegre modüler aviyonik mimarisi |
| **LLR** | Low-Level Requirements | DO-178C | Alt seviye tasarım gereksinimleri |
| **MC/DC** | Modified Condition/Decision Coverage | DO-178C (DAL A) | Değiştirilmiş durum/karar yapısal kod kapsamı |
| **MISRA** | Motor Industry Software Reliability Association | MISRA C/C++ | Emniyetli C/C++ kodlama kural seti |
| **PSSA** | Preliminary System Safety Assessment | ARP 4761A | Ön sistem emniyet değerlendirmesi |
| **RTA** | Run-Time Assurance | ASTM F3269 | Çalışma zamanı emniyet güvence mimarisi |
| **RTM** | Requirements Traceability Matrix | V-Model / DO-178C | Çift yönlü gereksinim izlenebilirlik matrisi |
| **SEU** | Single Event Upset | DO-254 / Uzay | İyonlaştırıcı radyasyon kaynaklı bit devrilmesi |
| **SIL** | Safety Integrity Level | IEC 61508 / EN 50128 | Endüstriyel ve raylı sistem emniyet seviyesi (SIL 1 - 4) |
| **SOTIF** | Safety of the Functionality | ISO 21448 | Hata olmasa dahi fonksiyonun sınırlarından doğan riskler |
| **SSA** | System Safety Assessment | ARP 4761A | Nihai sistem emniyet değerlendirmesi |
| **STPA** | System-Theoretic Process Analysis | STAMP / MIT | Sistem teorik süreç analizi (kontrol döngüsü odaklı) |
| **TMR** | Triple Modular Redundancy | Donanım Mimarisi | Üçlü modüler yedeklilik ve çoğunluk oylayıcı |
| **WCET** | Worst-Case Execution Time | RTOS / DO-178C | En kötü durum icra süresi |
